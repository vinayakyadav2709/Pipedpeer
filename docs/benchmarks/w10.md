# W10 speedups: before and after

**Every number here is emulated.** The lab is equal containers (2 CPUs each,
same memory) with links shaped by tc netem, all on one host. Speedup is 1
container against N containers of the same size. It is never measured against
the 15-core host, and it is not a real-hardware number.

## Method

- BEFORE: the binary built from `c7e2c7f` (the pure-move split), kept in
  `~/.local/share/pipedpeer-bench/bin/`. AFTER: the tree under test.
- Rig: `scripts/lab-emu.sh`. Runner: `scripts/bench-lib.sh`. Driver:
  `scripts/bench-w10.sh`. The case table at the top of the driver gives every
  workload, profile and flag.
- Every case runs the same workload with the same flags on both binaries, so
  a changed default (int8 on, fp32 averaging) shows up as a user would see it.
  Only a renamed feature gets separate flags: diloco runs
  `PIPEDPEER_DDP_SYNC_EVERY=auto` on BEFORE and `--ddp-sync fast` on AFTER.
- Each workload is warmed once (environment built and shipped) before the
  timed runs. `cold` builds on a fresh lab for each repetition.
- Metrics, each the median of 3:
  - `wall`: the whole `pipedpeer run`, timed from outside.
  - `script`: the workload's own timed section.
  - For the training cases also `sync` (ddp_sync steps from steps.json, else
    the shim's line) and `loss` (validation loss).
- Groups:
  - pool: 3 nodes x 1.5g, plus a 1-node baseline (`n1`).
  - train: 2 x 2g, plus `n1`.
  - hub: 3 x 1.5g.
  - cold: 3 x 1.5g, a fresh lab per repetition.
- Every timed run holds `~/.cache/pipedpeer-bench.lock`.
- Lab artifact: `os.cpu_count()` inside a container reports the host's 16
  cores, not its 2-CPU quota. So `Pool()` starts 14 workers on 2 CPUs. Both
  binaries get the same, so the comparison stands, but the absolute times
  include that oversubscription.

```sh
scripts/bench-w10.sh before                    # BEFORE column
scripts/bench-w10.sh after                     # AFTER column (verify pass)
scripts/bench-w10.sh table                     # medians as markdown
CASES="poolsend zstd" scripts/bench-w10.sh after
```

Raw rows: `~/.local/state/pipedpeer/bench/w10/results.csv`, with logs beside it.

Row notes:
- diloco: no sync (B1 swallowed), so the ranks trained alone. c7e2c7f logs
  "torch interception unavailable: invalid literal for int() with base 10:
  'auto'" and carries on without the ring. These are not DiLoCo numbers.
- overlap: no ring formed. The coordinator said "fewer than 2 eligible nodes,
  running single-node" (world 1) under that load. It is not a ring number.
- int8: c7e2c7f syncs in fp16 by default. Sync was 60.1 s of the 77.1 s
  script on wifi.
- Missing: nohub (3 nodes), the one-node training baselines and cold. The
  memory cap stayed full of other labs for over an hour, so QUIET-RERUN fills
  them.
- Discarded: the first training rows, from a bench model that did not learn
  (SGD sat at ln 2 even on one device; train.py now uses Adam). They are kept
  in `~/.local/state/pipedpeer/bench/discarded/`.

## AFTER (tree under test), emulated

QUIET-RERUN, 2026-10-16: the rows the paper cites, BEFORE and AFTER in
one session on an idle host (no other lab or agent; the load column is the
lab's own daemons). 3 x (2 CPU, 1.5 GB), medians of 3, warm environment
(`BL_EMU=scripts/lab-emu-warm.sh`, one warm set per binary) except `cold`
(`LAB_COLD=1`, a fresh lab per repetition). AFTER = 6a24715 for the warm pool
rows and 90dac09 for cold and the forced row (neither commit touches the pool
path). Rows in `~/.local/state/pipedpeer/bench-quiet/w10/`.

| case | profile | before wall s | after wall s | before script s | after script s | where AFTER ran |
|---|---|---|---|---|---|---|
| poolsend | lan | 4.07 | 2.00 | 2.58 | 0.98 | node 1 only |
| poolsend, `PIPEDPEER_DISTRIBUTE=force` | lan | 4.11 | 2.27 | 2.65 | 1.25 | node 1 only (the race kept every chunk) |
| chunksize | wifi | 1.82 | 0.57 | 1.11 | 0.30 | node 1 only |
| prefetch | 5g | 2.13 | 1.07 | 1.23 | 0.68 | 3 nodes |
| tail | wifi | 2.11 | 1.23 | 1.41 | 0.96 | 3 nodes |
| stats | wifi | 1.85 | 0.88 | 1.16 | 0.60 | 3 nodes |
| noop | lan | 0.64 | 0.23 | 0.00 | 0.00 | node 1 |
| cold | lan | 112.9 | 115.9 | 0.61 | 0.28 | env build 81-104 s + send 26-34 s (AFTER) |

Row notes:
- poolsend and chunksize: AFTER keeps the map on the submitting node, so
  the run records show no remote chunk. Its cost model predicts that local is
  faster. BEFORE shipped the chunks and lost to one node: poolsend n1 was 3.59 s
  under load. Forcing does not change that: the cost model is skipped, but the
  race still finished every chunk on node 1 before a peer could, so no request
  body was built. The lab cannot time the body build, so it is timed directly
  below.
- prefetch, tail, stats: every AFTER run sent chunks to both peers (one tail
  repetition used only one) and finished in about half of BEFORE's wall time.
- noop: an empty script, so the wall time is the overhead (environment
  seed, wrapper, dispatch). It dropped from 0.64 s to 0.23 s.
- cold: both binaries spend the time fetching from cache.nixos.org at the
  lab's download speed, so the two are equal within the repetitions'
  spread (80-129 s).

Request body build, 100 MB, timed directly (`taskset -c 2 python3 scripts/bench-poolbody.py`): c7e2c7f's `body +=` loop
(shim_pool.go:1153-1157) against `_frames_body` (transfer.py:204-213). Host
Python 3.14.8 pinned to one core, idle host, bench lock held, median of 3.
Both builds return identical bytes.

| items x size | before (`body +=`) | after (join) |
|---|---|---|
| 12 x 8.3 MB | 0.392 s | 0.056 s |
| 100 x 1 MB | 2.766 s | 0.056 s |
| 1000 x 100 KB | 18.310 s | 0.057 s |

The old build grows with the square of the item count, and the new one stays
flat at the cost of one copy.

```sh
export BL_OUT=~/.local/state/pipedpeer/bench-quiet BL_EMU=scripts/lab-emu-warm.sh
ONLY="poolsend:n3 noop:n3 chunksize:n3 prefetch:n3 tail:n3 stats:n3" LAB_WARM_SET=bench-after scripts/bench-w10.sh after
ONLY="poolsend:n3 noop:n3 chunksize:n3 prefetch:n3 tail:n3 stats:n3" LAB_WARM_SET=bench-before scripts/bench-w10.sh before
LAB_COLD=1 ONLY="cold:n3" scripts/bench-w10.sh after    # and before
```
